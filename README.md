# Mitospricecl

Comparador web de precios para cartas de Mitos y Leyendas en Chile.

## Despliegue
Proyecto estático, sin proceso de build.

- Netlify publish directory: `.`
- Archivo principal: `index.html`

## Archivos
- `index.html`: interfaz
- `styles.css`: diseño responsive
- `data.js`: publicaciones demo
- `app.js`: búsqueda, filtros, orden, favoritos y oportunidades
- `netlify.toml`: configuración de Netlify

## Estado
Esta versión funciona inmediatamente con datos demo y queda preparada para reemplazar `data.js` por una fuente real de precios.
